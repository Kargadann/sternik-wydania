# Sternik

*Trzyma kurs Twojego planu – decyzje zostają przy Tobie.*

Sternik to program dla Windows, który pilnuje Twojego długoterminowego planu inwestycyjnego (IKE, IKZE, rachunek zwykły w XTB) i oszczędności (lokaty, konta, obligacje skarbowe): liczy proporcje, przypomina o terminach, wpłatach i przeglądach, prowadzi księgę transakcji i pomaga porównać PIT-38 z PIT-8C.

**Sternik nie daje rekomendacji inwestycyjnych** – pilnuje zasad, które sam ustalisz.

## Pobierz
Najnowsza wersja: **[Wydania → Latest](../../releases/latest)** – plik `Sternik-…-instalator.exe`.

Przy pierwszym uruchomieniu instalatora Windows może pokazać okno „System Windows ochronił ten komputer” (program nie ma płatnego podpisu cyfrowego) – kliknij **„Więcej informacji” → „Uruchom mimo to”**. Instalacja nie wymaga uprawnień administratora.

## Instrukcja
[INSTRUKCJA.md](INSTRUKCJA.md) – instalacja, pierwsze uruchomienie, codzienne używanie, kopie zapasowe i aktualizacje.

## Prywatność
Twoje dane zostają **tylko na Twoim komputerze** (`%APPDATA%\Sternik`). Program nie wysyła ich nigdzie. Raz dziennie pyta tę stronę o numer najnowszej wersji – bez żadnych danych.

## Wymagania
Windows 10 lub 11 (64-bit).

To repozytorium zawiera tylko wydania i instrukcję.
